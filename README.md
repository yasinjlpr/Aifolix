# Aifolix

**Convert AI-generated folder structures into ready-to-run shell scripts.**

PathForge is a lightweight tool that converts a folder/file structure generated by AI into a script that can automatically create the entire project structure for you.

Instead of manually creating dozens of folders and files, simply paste the structure, choose your preferred shell, and generate the script.

## Features

- Convert AI-generated folder structures into executable scripts
- Support for multiple shell environments
- Simple and minimal interface
- Paste, open, or load a structure from a file
- Preview the detected project structure
- Copy generated code instantly
- Save the generated script to your computer

## How to Use

### 1. Get a project structure

Ask an AI to generate a folder structure for your project.

Example:

```text
website/
├── public/
│   ├── images/
│   └── favicon.ico
├── src/
│   └── main.js
└── package.json
```

### 2. Paste it into PathForge

Paste the structure into the **Project Structure** box.

You can also use **Paste**, **Open**, or drag & drop a supported `.txt`, `.tree`, or `.md` file.

### 3. Choose your shell

Select the desired output language from the **Language** dropdown.

### 4. Generate

Click **Generate**.

PathForge detects the folders and files and converts them into a script that can recreate the structure automatically.

### 5. Use the generated script

Copy the generated code or click **Save** to save it as a script file.

Now you can run the script and create the entire project structure without manually creating each folder and file.

## Why PathForge?

Creating a project structure manually is repetitive and wastes time.

PathForge turns this:

```text
AI-generated structure
        ↓
     PathForge
        ↓
   Shell script
        ↓
Complete project structure
```

into a quick and repeatable workflow.
